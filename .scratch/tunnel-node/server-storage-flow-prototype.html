主 Server 事务草模

这张一次性草模用来检查一个问题：按 Node 保留资源、端口池保存即生效、Client 延迟切换、分阶段轮换 Token 后，Server 的记录能否始终清楚表达“谁归哪个 Node、什么还没完成”。点击操作后，可查看完整状态和拒绝原因。

只演示设计逻辑。 所有数据都在浏览器内存中；刷新即重置。这里的“提交”模拟单笔数据库事务，不连接真实 SQLite、Node 或 FRPS。
